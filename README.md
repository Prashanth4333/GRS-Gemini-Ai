# 🎁 Gift Recommendation Platform using Gemini AI

An intelligent and interactive web application that suggests personalized gifts using **Gemini AI** and modern frontend technologies. This platform analyzes user preferences through a fun and engaging UI and offers gift ideas tailored to different occasions and personalities.

![Made with React, Tailwind CSS, Gemini AI]

---

## 🧠 About the Project

This Gift Recommendation Platform leverages Google's **Gemini AI** (via `@google/generative-ai`) to generate personalized gift suggestions. Users fill out a small form or questionnaire, and based on their answers, the AI recommends thoughtful and relevant gifts.

The app is enhanced with:
- **Parallax Tilt Effects** (`react-parallax-tilt`)
- **Animated Snowfall** (`react-snowfall`)
- **Beautiful Icons** (`lucide-react`)
- **Smooth Routing** (`react-router-dom`)

---

## ✨ Features

- 🎯 AI-powered gift recommendations (Gemini AI & OpenAI)
- 🎨 Fully responsive UI with Tailwind CSS
- ❄️ Holiday-themed snowfall effect
- 🎢 Parallax tilt animation for cards
- 🔁 Smooth client-side routing
- 🧩 Modular, scalable TypeScript architecture

---

## 🚀 Tech Stack

- **Frontend**: React.js + TypeScript + Tailwind CSS
- **AI Integration**: Gemini AI (`@google/generative-ai`) + OpenAI (`openai`)
- **Routing**: React Router DOM
- **Build Tools**: Vite, PostCSS
- **Effects/Animations**: `react-snowfall`, `react-parallax-tilt`, `lucide-react`

## 🛠️ Getting Started

### ✅ Prerequisites

- Node.js (v16 or later)
- npm
- Gemini AI API Key from Google AI Studio
- (Optional) OpenAI API Key if used in parallel

---

### 📦 Clone and Install

```bash
git clone https://github.com/your-username/gift-recommendation-platform.git
cd gift-recommendation-platform
npm install

---

### 🔐 Set Up Environment Variables
Create a .env file in the root with your Gemini AI key:

VITE_GEMINI_API_KEY=your_gemini_api_key
# Optional:
VITE_OPENAI_API_KEY=your_openai_api_key

---

###  ▶️ Run Locally (VS Code or Terminal)
npm run dev
App runs at: http://localhost:5173
